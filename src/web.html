下载并连上服务端

客户端装在要被访问的那台机器上，由它主动连出。服务端只负责接受访问，再让客户端去拨目标地址。下面的命令已经填好这台服务端的控制地址，密钥位置留空。

macOSApple 芯片。下载后执行 chmod +x。 Linux x86_64下载后执行 chmod +x。依赖系统的 libc 和 zlib。 Windows x86_64只包含客户端。在命令提示符里直接运行。

连接之前

  1. 选和机器对应的文件。macOS 包不能在 Intel 芯片上跑，Windows 包不能用来启动服务端。
  2. 把命令里的 <api-key> 换成管理员给你的密钥。这个页面不会写出密钥。
  3. --server 是控制通道，客户端只连这一个地址。数据通道在握手之后自动建立。
  4. --name 是这台客户端的名字。同一个名字再次连接会替换旧会话，管理页上的映射按这个名字交给它。
  5. -m 左边是服务端要监听的 ip:port，右边是客户端能访问的 host:port。可以写多条。

例子。0.0.0.0:18080=127.0.0.1:8080 表示：别人访问这台服务端的 18080，流量转到客户端自己的 8080。0.0.0.0 对公网开放，127.0.0.1 只有服务端这台机器能连。目标可以是客户端能到达的任意地址，例如 192.168.1.9:22。目标当时没在监听，映射仍会保留，并在「事件」里记一条失败。

端口映射

    
一条映射把服务端上的一个端口交给某个在线客户端。客户端命令行带上的映射标记为 cli，在这里创建的标记为 api。cli 映射会在同名客户端重连时按它当时的命令更新；api 映射会一直留着，直到在这里关闭。
