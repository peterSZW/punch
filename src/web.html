PUNCH
反向 TCP 隧道

下载并连上服务端

客户端装在要被访问的那台机器上，由它主动连出。管理员先在「账号」里建好客户端，再把 secret 交给那台机器。这个页面不会写出 secret。

macOSApple 芯片。下载后执行 chmod +x。 Linux x86_64下载后执行 chmod +x。依赖系统的 libc 和 zlib。 Windows x86_64只包含客户端。在命令提示符里直接运行。

连接之前

  1. 选和机器对应的文件。macOS 包不能在 Intel 芯片上跑，Windows 包不能用来启动服务端。
  2. 把 <secret> 换成管理员给你的那一把。管理页的 api key 不能拿来连接。
  3. --server 是控制通道，客户端只连这一个地址。数据通道在握手之后自动建立。
  4. 同一把 secret 只能有一台机器连着。另一台用它登录时，原来的那台会退出，并且不再重连。
  5. 连接时不要带 -m。映射在管理页里改。被允许的客户端连上之后，可以用 punch map 自己改。

端口映射

    
一条映射把服务端上的一个端口交给某个客户端。客户端当时不在线也可以先建，它下次连上会自动用这里的最新配置。改监听或目标后马上生效。

  1. 先在「账号」里建客户端。下拉框里没有名字时，不能从这里新建。离线的也可以先建映射。
    2. 
          
  2. 0.0.0.0 表示按服务端所在机器的网卡对外。只想给本机程序用时选 127.0.0.1。
    3. 
          
  3. 监听地址必须是 IP，不能写域名。目标可以写 IP 或客户端能解析的主机名。
    4. 
          
  4. 创建之后客户端会马上试连一次。连不上时这一行变红，映射不会被删掉。
